# Student Course Registration System

A Java-based console application developed as part of the CodSoft Java Development Internship.

## 📌 Project Overview

The Student Course Registration System allows students to view available courses, register for courses, view registered courses, and remove courses.

The application manages course capacity and prevents duplicate course registration.

## 🎯 Objective

The objective of this project is to demonstrate:

- Object-Oriented Programming
- Classes and objects
- Collections
- Course management
- Student registration
- Input validation
- Capacity management

## ✨ Features

- Display available courses
- Course details
- Course capacity management
- Student registration
- Prevent duplicate registration
- Remove registered courses
- View registered courses
- Input validation
- Menu-driven interface

## 🏗️ Project Structure

```text
CODSOFT_CourseRegistrationSystem
│
├── Course.java
├── Student.java
├── CourseRegistrationSystem.java
└── README.md
```

### Course.java

Stores course information such as course code, title, description, capacity, and schedule.

### Student.java

Stores student information and manages registered courses.

### CourseRegistrationSystem.java

Provides the main menu and manages the registration system.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming
- Java Collections Framework
- Scanner
- ArrayList

## ▶️ How to Run

### Compile

```bash
javac Course.java
javac Student.java
javac CourseRegistrationSystem.java
```

### Run

```bash
java CourseRegistrationSystem
```

## 🔄 Available Operations

1. View Available Courses
2. Register for a Course
3. Remove a Course
4. View My Courses
5. Exit
